# ترصد ثان المحلة — طريقة النشر (مجاني)

## 1) قاعدة البيانات (Neon — مجانية)
1. سجّل في https://neon.tech وأنشئ Project.
2. انسخ رابط الاتصال (Connection string) ويبدأ بـ `postgresql://`.

## 2) رفع الكود
1. أنشئ حساب على https://github.com وارفع محتويات هذا المجلد في Repository جديد (Private).

## 3) السيرفر (Render — مجاني)
1. سجّل في https://render.com واختر New > Web Service ثم اربطه بالـ Repository.
2. Build Command: `npm install`  |  Start Command: `npm start`
3. من Environment أضف:
   - `DATABASE_URL` = رابط Neon
   - `ADMIN_PASSWORD` = كلمة سر الإدارة (اختر كلمة قوية)
4. بعد النشر هتاخد رابط مثل `https://xxxx.onrender.com` — ده رابط التطبيق.

## الاستخدام
- الإدارة: افتح الرابط > "دخول الإدارة" > كلمة السر > تبويب المستخدمين > أضف مستخدم > "إرسال على واتساب".
- الموظف: يفتح الرابط ويدخل برقم تليفونه والكود.
- على الموبايل: من قائمة المتصفح اختر "إضافة إلى الشاشة الرئيسية".

## ملاحظات
- الخطة المجانية في Render بتنام بعد فترة خمول، فأول فتح ممكن ياخد نصف دقيقة.
- البيانات محفوظة في Neon وليست على Render، فمش بتضيع عند إعادة التشغيل.
- الكود يتقفل 15 دقيقة بعد 5 محاولات غلط، والجلسة تنتهي بعد 30 يوم.
